# Data_Analysis_Agent

一个基于SQLite和工具调用的数据分析Agent，用于练习Agent循环、只读SQL查询、多表分析、错误处理和评测。

- [ ]创建数据库表结构

- [ ]实现表结构提取工具
- [ ]实现只读SQL查询工具
- [ ]实现Agent循环
- [ ]建立初版评测集

## 项目目标

计划实现功能：

- 多表JOIN和聚合查询
- 订单、商品、客户和分类分析
- 商品状态历史和订单状态历史分析
- 日终库存趋势和库存变动归因
- 结构化错误返回
- 多轮工具调用
- 调用轨迹和评测记录

## 技术栈与环境

- Python 3.14.5
- SQLite
- Python标准库`sqlite3`
- venv
- DeepSeek Function Calling
- Gradio暂作为后续交互入口

第三方依赖见`requirements.txt`

## 设计边界

- 当前只允许Agent执行只读查询

- 当前不实现增删改
- 当前不实现图表和文件导出
- 当前不迁移到MySQL或FastAPI
